Данные подробного анализа запрашиваются только для выбранного контракта, чтобы не перегружать публичный API.
Методика и ограничения.
• Фильтр: статус Trading + LinearPerpetual + расчётная монета USDT + turnover24h ≥ 5 000 000 USDT.
• 24ч — скользящее окно, которое публикует Bybit, а не календарные сутки.
• CVD Buy/Sell/Delta за 5м / 15м / 1ч / 24ч рассчитывается по доступной REST-выборке и сделкам WebSocket с момента подключения. Звёздочка отмечает неполное покрытие окна; полная 24ч история не гарантируется.
• OI — сравнение доступных точек 5-минутной и часовой истории; метки цены/OI описывают сочетание динамики, но не доказывают направление позиций.
• VWAP — приближение по часовым свечам; Volume Profile строится по 5-минутным свечам за 1ч/24ч, POC и Value Area (около 70%) являются оценкой по типичной цене свечи, не footprint.
• Ликвидации: Buy означает ликвидацию лонга, Sell — шорта. Доступна история текущей сессии WebSocket; архивный REST-метод для публичной полной истории в этом мониторе не используется.
Панель описывает рыночные данные и не формирует торговых рекомендаций.
